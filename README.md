# Scanned ISBN to Book Data

This program will use https:/openlibrary.org APIs to return book info.

## Order of Operations

The first step is to load the list of barcodes that were generated by the Scan
ISBN to Inventory Apple Shortcut.
This will be saved to a database.
Initially will be saved to PostgreSQL.
If a barcode already exists, it will get updated.
The next step is to use the Open Library APIs to get the book info and author
info into database tables.
This should only be for any new books.
Finally, there should be a GUI/TUI/web interface to be able to search for books.
